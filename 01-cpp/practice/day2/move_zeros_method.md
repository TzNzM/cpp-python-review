# `move_zeros` 推荐方法

## 一、核心思路：读指针和写位置

维护两个变量：

```text
read  —— 当前正在检查的下标
write —— 下一个应该放置非零元素的位置
```

遍历数组时：

1. 如果 `values[read]` 是 `0`，跳过；
2. 如果它不是 `0`，就把它放到 `write` 位置；
3. `write` 向后移动一格。

非零元素处理完以后，`write` 后面的区域自然就是零。

## 二、参考实现

```cpp
#include <utility>

void move_zeros(int* values, int n) {
    if (values == nullptr || n <= 0) {
        return;
    }

    int write = 0;
    for (int read = 0; read < n; ++read) {
        if (values[read] != 0) {
            if (write != read) {
                std::swap(values[write], values[read]);
            }
            ++write;
        }
    }
}
```

这个方法只在原数组内部交换，不创建第二个数组。

## 三、手动运行过程

输入：

```text
[0, 1, 0, 3, 12]
```

处理过程：

```text
read=0，遇到 0，跳过
read=1，遇到 1，放到 write=0 -> [1, 0, 0, 3, 12]
read=2，遇到 0，跳过
read=3，遇到 3，放到 write=1 -> [1, 3, 0, 0, 12]
read=4，遇到 12，放到 write=2 -> [1, 3, 12, 0, 0]
```

非零元素 `1、3、12` 的相对顺序没有改变，零全部位于末尾。

## 四、为什么这种方法更安全

原来的写法需要访问 `values[i + count]`，并且还会在 `count++` 后再次使用新的下标，边界情况比较难保证。

这个方法中：

- `read` 始终在 `0` 到 `n - 1` 范围内；
- `write` 不会超过 `read`；
- 每次数组访问都使用已知合法的下标；
- 不需要寻找“下一个非零元素”的位置。

## 五、复杂度

- 时间复杂度：`O(n)`；
- 额外空间复杂度：`O(1)`；
- 非零元素的相对顺序保持不变。

