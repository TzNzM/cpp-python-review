# C++/Python 面试能力恢复学习计划

## 学习原则

- 目标是恢复独立编码能力，不以看懂 AI 代码代替自己实现。
- 每天遵循：知识回忆 -> 独立练习 -> 编译运行 -> Debug -> Code Review -> 口述复盘。
- 默认先给任务、约束和测试，不直接给完整答案。
- 代码提交后重点检查：编译错误、逻辑错误、边界条件、复杂度和代码风格。
- C++ 已完成一轮以高频基础、STL 和面向对象为主的复习；未覆盖的专题按面试需要回补。
- 当前主线切换为 Python，目标是能独立读写深度学习训练代码、定位常见问题并完成小型实验。
- Python 学习遵循“语言基础 -> NumPy 数值计算 -> PyTorch 训练闭环”，每个知识点都要落到可运行的小实验。
- 每天保留 20--30 分钟完成 1 道数据结构/算法小题；优先选择与当天 Python 主题相关的题目，并重视独立推导。

## 当前学习路线：14 天 Python 恢复计划

本路线严格采用学习协议中的六个阶段。前 10 天恢复语言与工程能力，后 4 天选择“NumPy + PyTorch”方向；默认每天投入约 2--2.5 小时。每项编码练习均先自行实现，查文档后再运行、调试和复盘，不默认索取完整答案。

### 阶段 1：基础数据结构（Day 1--Day 2）

### Day 1：list、tuple、字符串与切片

- 回忆并验证：可变/不可变对象，索引、负索引、切片边界，`append` / `extend` / `insert` / `pop` / `remove`，元组解包；
- 独立任务 1：给定样本路径列表，实现不修改原列表的“过滤扩展名 + 去除空白 + 每 4 条分批”；
- 独立任务 2：解析形如 `class_000123.jpg` 的文件名，使用切片提取类别和编号；处理格式不合法的输入；
- 输出：记录 list 与 tuple 的使用选择、切片的左闭右开规则，以及至少两个实际踩坑。

### Day 2：dict、set 与复合数据结构

- 回忆并验证：字典增删查改、`get`、`items`、`setdefault`，集合去重、集合运算，嵌套容器；
- 独立任务 1：统计标签序列的类别频次和首次出现位置，比较 `dict[key]` 与 `dict.get` 的行为；
- 独立任务 2：根据 train/validation 文件名集合找交集、仅训练集样本和重复样本；
- 面试复盘：何时选择 list、tuple、dict、set？它们的查找/插入复杂度和常见误区是什么？

### 阶段 2：函数（Day 3--Day 4）

### Day 3：参数、返回值与默认参数

- 回忆并验证：位置参数、关键字参数、默认参数、返回多个值、参数传递与可变默认参数陷阱；
- 独立任务 1：编写数据划分函数，支持 `ratio`、`seed`、`shuffle` 等关键字参数，并校验输入；
- 独立任务 2：故意复现“默认 list 被多次调用共享”的问题，再修正并说明原因；
- 输出：为两个函数写 docstring、类型注解和至少各两组边界测试。

### Day 4：`*args`、`**kwargs` 与作用域

- 回忆并验证：参数收集/解包，LEGB 作用域，`global` / `nonlocal` 的含义及谨慎使用原则；
- 独立任务 1：实现可配置的指标汇总函数，接收任意数值与可选命名参数；
- 独立任务 2：实现计数器闭包，解释内部状态为何能保留；分别尝试局部变量遮蔽和 `nonlocal`；
- 面试复盘：默认参数在定义时还是调用时求值？`*args` 与 `**kwargs` 分别解决什么问题？

### 阶段 3：Python 特性（Day 5--Day 6）

### Day 5：推导式与常用迭代工具

- 回忆并验证：列表/字典/集合推导式，条件推导式，`enumerate`、`zip`、`sorted`、`any` / `all`；

- 独立任务 2：将两列预测结果与标签配对，计算正确样本索引；禁止先写显式 `for` 循环；
- Debug：阅读一段嵌套推导式，改写为普通循环并判断何时推导式反而降低可读性。

### Day 6：迭代器、生成器与 `yield`

- 回忆并验证：可迭代对象与迭代器的区别，`iter` / `next`，生成器表达式，`yield` 的暂停与恢复；
- 独立任务 1：写一个按 batch 产出样本索引的生成器，支持 shuffle，正确处理最后不足一批的数据；
- 独立任务 2：比较 list 返回和 generator 返回的重复遍历行为；用一个小实验说明“迭代耗尽”；

### 阶段 4：对象模型（Day 7--Day 8）

### Day 7：类、`__init__` 与实例状态

- 独立任务 2：实现 `MetricTracker`，支持更新累计值、计算平均值和重置；
- Debug：分别修改类属性和实例属性，记录各实例可见结果并解释原因。

### Day 8：继承、`property` 与魔术方法

- 回忆并验证：继承与 `super()`，`@property` / setter，`__repr__`、`__str__`、`__len__`、`__iter__`、`__eq__` 的常见用途；
- 独立任务 1：为 `SampleRecord` 添加受控的标签 property，并让非法标签不能写入；
- 独立任务 2：实现一个轻量 batch 容器，提供长度、可读打印和按索引访问；
- 面试复盘：`__repr__` 与 `__str__` 的区别；为何 property 能在不破坏调用方的前提下加入校验？

### 阶段 5：工程能力（Day 9--Day 10）

### Day 9：异常、文件与 `with`

- 独立任务 2：把处理结果安全写入新文件，确保异常发生时不会留下半成品；

### 阶段 6：按岗位选择——NumPy + PyTorch（Day 11--Day 14）

### Day 11：NumPy ndarray、索引与形状

- 回忆并验证：`ndarray` 的 `shape`、`ndim`、`dtype`，切片/布尔索引，`reshape`、`transpose`、`squeeze`、`expand_dims`，view 与 copy；
- 独立任务 1：构造图像 batch `(N, C, H, W)`，完成样本筛选、通道选择和 `NCHW` / `NHWC` 变换；每一步断言 shape；
- 独立任务 2：将标签转为 one-hot，并检查索引越界和 dtype；
- 复盘：用自己的话解释“shape 错误”通常先看什么。

### Day 12：NumPy 广播、向量化与数值计算

- 回忆并验证：广播规则、`axis`、`keepdims`、聚合操作、逐元素运算与矩阵乘法 `@`；
- 独立任务 1：用向量化实现 batch 的标准化、准确率和混淆矩阵核心统计，避免逐样本 Python 循环；
- 独立任务 2：实现数值稳定的 softmax 和交叉熵；用极大/极小 logits 检查 `NaN` / `Inf`；
- Debug：对一个广播失败示例，逐维写出两个数组的 shape 并修正。

### Day 13：PyTorch Tensor、Autograd 与模型

- 回忆并验证：Tensor 的 dtype/device/shape，NumPy 转换的共享内存，`.to(device)`，`requires_grad`、`backward`、`zero_grad`、`detach`；

- 独立任务 3：实现两层 MLP，检查 `nn.CrossEntropyLoss` 的 logits 和标签形状/类型。

### Day 14：Dataset、DataLoader 与训练闭环

- 回忆并验证：自定义 `Dataset` 的 `__len__` / `__getitem__`，DataLoader 的 batch、shuffle、`drop_last`，`model.train()`、`model.eval()`、`torch.no_grad()`；
- 独立任务 1：为小型分类数据集写 Dataset 和 DataLoader，逐 batch 输出 shape、dtype、device 与标签范围；
- 独立任务 2：完成训练/验证循环：前向 -> loss -> 清梯度 -> 反向 -> 更新；正确累计平均 loss 与 accuracy；
- 独立任务 3：保存最佳 `state_dict`，重新加载验证；先在极小样本集上过拟合作为管线自检；
- 最终复盘：从空白文件口述并写出训练脚本结构；定位至少三类问题（shape、dtype/device、梯度或 train/eval 状态）。
