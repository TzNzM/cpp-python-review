# C++/Python 面试能力恢复学习计划

## 学习原则

- 目标是恢复独立编码能力，不以看懂 AI 代码代替自己实现。
- 每天遵循：知识回忆 -> 独立练习 -> 编译运行 -> Debug -> Code Review -> 口述复盘。
- 默认先给任务、约束和测试，不直接给完整答案。
- 代码提交后重点检查：编译错误、逻辑错误、边界条件、复杂度和代码风格。
- 当前阶段优先完成 C++ 高频基础和 STL，再进入继承、多态和接口。
- 暂不强制每天安排独立算法题；优先保证语言基础、容器和工程代码能力。

## 当前学习路线

### Day 5：vector、string + iterator

重点：

- 使用迭代器遍历 `vector` 和 `string`；
- `iterator` 与 `const_iterator`；
- `erase` 返回的新迭代器；
- `insert` 插入元素；
- 插入、删除后迭代器可能失效的情况。

练习：

1. 使用迭代器删除 `vector` 中的负数；
2. 使用 `const_iterator` 统计字符串元音；
3. 使用迭代器向有序 `vector` 中插入元素。

### Day 6：list、deque + iterator

重点：

- `list` 与 `vector` 的存储和插入删除差异；
- `deque` 的特点和适用场景；
- 不同容器迭代器的使用方式；
- `erase` 后迭代器的处理。

### Day 7：map、unordered_map

重点：

- key/value 结构；
- `find`、`count`、`insert`、`emplace`、`operator[]`；
- 有序 `map` 与哈希表 `unordered_map` 的区别；
- 遍历键值对；
- 访问不存在的 key 时的差异。

### Day 8：set、unordered_set、queue、stack、priority_queue

重点：

- 集合去重；
- 有序集合与哈希集合；
- 容器适配器的接口限制；
- FIFO、LIFO 和优先级队列；
- 典型使用场景和复杂度。

### Day 9：algorithm + 迭代器

重点：

- `find`、`find_if`；
- `count`、`count_if`；
- `sort`、`reverse`；
- `remove`、`remove_if`；
- `transform`、`accumulate`；
- “算法不真正删除元素”的 erase-remove 习惯用法。

### Day 10：继承与类层次结构

重点：

- 基类和派生类；
- `public` 继承；
- 基类构造函数和派生类构造函数顺序；
- 成员访问权限；
- `protected` 的使用边界。

### Day 11：virtual、override 与多态

重点：

- 虚函数；
- `override`；
- 基类指针/引用调用派生类行为；
- 静态类型与动态类型；
- 虚析构函数。

### Day 12：纯虚函数、抽象类和接口

重点：

- 纯虚函数；
- 抽象类；
- C++ 中用抽象类表达接口；
- 面向接口编程；
- 多态对象的资源管理。

### Day 13：综合练习

使用 `Shape` 或 `Employee` 设计一个小型多态系统，综合：

- 类和封装；
- 继承；
- 虚函数；
- 抽象接口；
- `vector` 保存基类指针或智能指针；
- 生命周期和资源管理。
