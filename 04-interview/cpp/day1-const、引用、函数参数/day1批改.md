# Day 1：const、引用、函数参数

## 一、`int`、`int&`、`const int&` 作为参数的区别

### 1. `int x`：按值传递

```cpp
void f(int x);
```

调用函数时，会把外部变量的值复制一份给 `x`。函数内部修改 `x`，不会影响外部变量。

### 2. `int& x`：引用传递

```cpp
void f(int& x);
```

`x` 是外部变量的别名，不是一个新的副本。函数内部修改 `x`，就会直接修改外部变量。

引用通常用于：

- 让函数修改调用者的变量；
- 避免复制较大的对象；
- 作为函数的输出参数。

“引用是地址”这个说法不够准确。引用底层通常可以通过地址实现，但引用不是指针，不需要使用 `*` 解引用。

### 3. `const int& x`：只读引用

```cpp
void f(const int& x);
```

它仍然是外部对象的别名，不会复制对象；但通过 `x` 不能修改对象。它适合函数只读取对象、对象较大而不希望复制，以及需要绑定临时对象的情况。

对于 `int` 这种很小的类型，按值传递通常已经足够；对于 `string`、容器或自定义大对象，`const&` 更常见。

## 二、`int*`、`const int*`、`int* const`

### 1. `int* p`

`p` 是一个指向 `int` 的指针：可以改变 `p` 的指向，也可以通过 `*p` 修改它指向的整数。

### 2. `const int* p`

也可以写成 `int const* p`，表示“指向 const int 的指针”：可以改变 `p` 的指向，但不能通过 `p` 修改它指向的值。

### 3. `int* const p`

表示“const 指针，指向一个可以修改的 int”：`p` 初始化后不能改指向，但可以通过 `*p` 修改它指向的值。

记忆方式：

```text
const int* —— 指向的值不能改
int* const —— 指针自己不能改
```

## 三、为什么引用参数可以返回多个结果？

假设函数需要计算三个结果：总分、最高分和及格人数。调用者先准备三个变量：

```cpp
int sum = 0;
int max_score = 0;
int passed_count = 0;

analyze_scores(scores, n, sum, max_score, passed_count);
```

函数参数写成引用：

```cpp
void analyze_scores(
    const int scores[],
    int n,
    int& sum,
    int& max_score,
    int& passed_count
);
```

此时，函数中的 `sum` 就是调用者的 `sum`，函数中的 `max_score` 就是调用者的 `max_score`，以此类推。它们只是同一个变量的两个名字。

因此函数内部执行：

```cpp
sum += scores[i];
```

实际上是在修改调用者的 `sum`。函数结束后，调用者仍然能看到修改后的结果。三个引用参数就分别对应三个输出位置：

```text
sum          -> 总分
max_score    -> 最高分
passed_count -> 及格人数
```

这里不是把函数内部的局部变量带出了函数。函数内部的局部变量在函数结束后会销毁；引用参数绑定的是调用者原本就存在的变量，函数只是通过别名修改它们。

### 和普通值传递对比

```cpp
void f(int x);   // x 是副本，修改 x 不影响外部变量
void f(int& x);  // x 是别名，修改 x 会影响外部变量
```

如果使用 `int x`，调用时会发生复制；如果使用 `int& x`，函数参数和调用者变量指向同一个对象。

### 为什么不用多个 `return`？

一个普通函数只能直接返回一个对象。如果要返回多个结果，可以使用引用参数、定义一个包含多个字段的结构体，或使用 `std::tuple` 等类型。

引用参数的优点是调用方式简单直接；缺点是调用者需要知道哪些参数会被函数修改。结构体返回值通常更容易表达结果的含义。

### 引用参数和指针参数

指针也可以作为输出参数：

```cpp
void f(int* result);
f(&sum);
```

函数内部需要通过 `*result` 修改值。引用的调用方式更自然：

```cpp
void f(int& result);
f(sum);
```

引用通常表达“这里必须传入一个有效变量”；指针可能为空，因此使用指针时还要考虑空指针检查。

## 四、数组复习

### 1. 数组的基本结构

```cpp
int values[5] = {10, 20, 30, 40, 50};
```

- 数组长度是 5；
- 下标从 0 开始；
- 合法下标是 `0` 到 `4`；
- 数组元素在内存中连续排列；
- `values[i]` 可以理解为 `*(values + i)`。

### 2. 如何计算数组长度

当数组还处于原始作用域时：

```cpp
int values[5] = {10, 20, 30, 40, 50};
size_t n = sizeof(values) / sizeof(values[0]);
```

这里的 `sizeof(values)` 是整个数组的大小，所以可以得到元素个数。

但是传入函数后：

```cpp
void f(const int values[]);
```

参数实际上会调整为：

```cpp
void f(const int* values);
```

数组传入函数后会退化为指针。函数只拿到了首元素地址，不再知道原数组有多少个元素。因此通常需要把长度一起传入：

```cpp
void f(const int* values, int n);
```

然后遍历下标 `0` 到 `n - 1`。不能在这种函数参数中使用 `sizeof(values) / sizeof(values[0])` 计算数组长度，因为此时 `values` 已经是指针。

### 3. `const int scores[]` 的含义

在成绩统计函数中：

```cpp
const int scores[]
```

表达了两层意思：

1. `scores` 传入函数后本质上是一个指针；
2. 函数只能读取数组元素，不能通过 `scores` 修改它们。

所以数组长度需要由额外的 `n` 提供，而 `const` 用来保护输入数组不被函数修改。

## 五、最终记忆总结

```text
int          -> 复制一份值
int&         -> 外部变量的别名，可以修改外部变量
const int&   -> 外部对象的只读别名
const int*   -> 指向的值不能通过指针修改
int* const   -> 指针本身不能改指向
```

```text
数组在原作用域中可以用 sizeof 计算长度；
数组传入函数后会退化为指针，必须额外传入长度。
```
