1、`int x`、`int& x`、`const int& x` 作为参数有什么区别？

int x 是按值传递，函数内部修改 `x`，不会影响外部变量。

int& x 引用是外部变量的别名。修改 `x` 就是在修改外部变量。你写的“代表输入的是地址”不够准确。引用底层通常通过地址实现，但语法和语义上它不是指针，也不需要使用 `*` 解引用。

const int& x引用本身不复制对象，但通过这个引用不能修改对象：它适合：

- 只读传入对象；
- 避免复制较大的对象；
- 允许绑定到临时对象。

对于 `int` 这种很小的类型，实际工程中通常直接按值传递即可。

2、`int*`、`const int*`、`int* const` 分别表示什么？

int* 是创建一个int类型的指针

const int*   —— 指向的值不能改，这个修饰的是int（常量指针）
int* const   —— 指针自己不能改，这个修饰的是const后面的指针（指针常量）

3、为什么函数需要用引用参数返回多个结果？

因为函数内部的变量都是局部变量，所以想要读取到这些变量，就需要使用引用参数返回拿到这些结果

4、statisic有什么用？

1.当在函数修饰静态变量时，其具有记忆功能，只初始化一次，所在函数再次被调用时静态变量的值保持上次的值不变

2.当在文件内时，修饰的变量和函数作用域均被限制在该函数内,在其他文件内的函数调用时会出现“不认识”的情况，不可被访问和调用。
