# Day 2 面试问题标准答案

## 1. 引用和指针调用时有什么区别？

调用形式由参数声明决定，不能只看 `f(x)` 或 `f(&x)` 判断。

```cpp
void by_value(int x);
void by_reference(int& x);
void by_pointer(int* x);
```

对应调用：

```cpp
int value = 10;

by_value(value);       // 传入一份值的副本
by_reference(value);   // 传入 value 本身的别名
by_pointer(&value);     // 传入 value 的地址
```

区别总结：

```text
值传递       —— 函数得到副本
引用传递     —— 函数参数是外部变量的别名
指针传递     —— 函数得到一个地址，需要通过 * 解引用
```

指针可以为空：

```cpp
int* p = nullptr;
```

引用必须绑定到一个有效对象，不能像指针一样表示空引用。

## 2. `int*`、`const int*`、`int* const` 分别表示什么？

### `int* p`：普通指针

```cpp
int a = 10;
int b = 20;
int* p = &a;

*p = 11;  // 可以修改 a
p = &b;   // 可以让 p 改为指向 b
```

指针指向的值和指针自己的指向都可以变化。

### `const int* p`：指向 const int 的指针

```cpp
int a = 10;
int b = 20;
const int* p = &a;

// *p = 11;  // 错误，不能通过 p 修改 a
p = &b;      // 可以改变 p 的指向
```

它只限制“通过这个指针修改指向的值”，不限制指针本身改变指向。也可以写成 `int const* p`。

### `int* const p`：const 指针

```cpp
int a = 10;
int b = 20;
int* const p = &a;

*p = 11;      // 可以修改 a
// p = &b;     // 错误，p 不能改指向
```

它限制的是指针本身，指针初始化后不能改指向；但指向的 `int` 仍然可以修改。

### 对比表

| 写法 | 能否修改 `*p` | 能否修改 `p` 的指向 |
|---|---:|---:|
| `int* p` | 可以 | 可以 |
| `const int* p` | 不可以通过 `p` 修改 | 可以 |
| `int* const p` | 可以 | 不可以 |

记忆方式：

```text
const int* —— 指向的值不能通过 p 修改
int* const —— 指针自己不能改指向
```

补充：`const int* const p` 表示指向 const int 的 const 指针，指向不能改，值也不能通过 `p` 修改。

## 3. `int a[4]` 中，`a`、`&a[0]`、`a + 1` 分别表示什么？

```cpp
int a[4] = {10, 20, 30, 40};
```

### `a`

数组名 `a` 在大多数表达式中会自动退化为指向第一个元素的指针：

```cpp
a       // 通常等价于 &a[0]
int* p = a;
```

数组名不是普通的可修改指针，不能写 `a = a + 1`。

### `&a[0]`

表示第一个元素的地址：

```cpp
&a[0] == a
```

发生数组到指针转换时，两者指向相同位置，类型都是 `int*`。

### `a + 1`

表示指向第二个元素的指针：

```cpp
a + 1 == &a[1]
*(a + 1) == a[1] == 20
```

指针加 1 不是增加 1 个字节，而是向后移动一个 `int` 元素的大小。

### 不要混淆 `&a`

```cpp
&a
```

表示整个数组的地址，类型是 `int (*)[4]`，和 `int*` 不一样。

```text
a       —— 通常退化为指向第一个元素的 int*
&a[0]   —— 第一个元素的地址，类型 int*
a + 1   —— 第二个元素的地址，类型 int*
&a      —— 整个数组的地址，类型 int (*)[4]
```

如果写 `&a + 1`，它会跨过整个 4 元素数组，而不是只跨过一个 `int`。

### 和 `sizeof` 的关系

在数组仍然是原始数组的作用域内：

```cpp
sizeof(a) / sizeof(a[0])  // 结果是 4
```

但传入函数后：

```cpp
void f(int a[]);
```

参数实际等价于 `void f(int* a)`。此时函数只得到首元素地址，不再知道数组长度，必须额外传入 `n`。

## 4. 局部 `static` 和普通局部变量的生命周期

```cpp
int next_id() {
    static int id = 99;
    return ++id;
}
```

普通局部变量每次进入函数时创建，函数返回时销毁，下一次调用重新创建并初始化。

局部 `static` 变量第一次执行到声明处时初始化，后续调用不会再次初始化，一直存在到程序结束，并保留上一次调用后的值；但它的作用域仍然只在当前函数内部。

连续调用 `next_id()` 会得到：

```text
100
101
102
```
