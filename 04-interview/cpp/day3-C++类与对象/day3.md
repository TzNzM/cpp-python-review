1. class 中 private 和 public 的区别是什么？
private 是只有在类的内部能访问到的，外部不能访问到
public 是在类的内部和外部都能访问到的
2. 为什么构造函数推荐使用初始化列表？
初始化列表是在进入构造函数函数体之前，直接初始化成员变量。相比先默认初始化再在函数体内赋值，它更直接、更高效；对于 const 成员、引用成员以及没有默认构造函数的成员，必须使用初始化列表。
3. 为什么只读成员函数要写成：
int area() const;
防止其中的变量被修改

const 成员函数承诺不会通过当前对象修改普通成员变量，因此可以被 const 对象调用，编译器也会帮助检查是否发生了修改。
4. 普通局部对象和局部 static 对象的析构时机有什么区别？
普通局部对象在该函数执行完成之后就析构了
局部 static 对象在整个程序执行完之后再析构

普通局部对象离开作用域时析构；
局部 static 对象第一次执行到声明时初始化；
局部 static 对象在整个程序结束时析构；
它的作用域仍然只在函数内部。
