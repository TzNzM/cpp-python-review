1、vector、list、deque 的底层结构有什么区别？
vector -> 连续的动态数组
list   -> 双向链表节点
deque  -> 分段存储的连续块
2、为什么 list 的头部和中间插入删除通常是 O(1)？
因为只需要修改指针指向就行(如果已经拥有目标位置的迭代器，list 的插入和删除通常是 O(1)；但如果需要先遍历寻找位置，寻找过程仍然是 O(n)。)
3、为什么 vector 的中间插入删除通常是 O(n)？
因为需要遍历数组，把数组中的数据删除则向前移动，增加则向后移动
4、deque 和 vector 都支持随机访问，它们有什么区别？
vector：
- 内存整体连续；
- 随机访问速度好；
- 尾部操作高效；
- 中间和头部插入删除成本较高；
- 扩容可能导致迭代器、指针和引用失效。

deque：
- 分段存储；
- 随机访问仍然是 O(1)；
- 头部和尾部操作都高效；
- 不保证整体内存连续；
- 迭代器失效规则和 vector 不完全相同。
5、list.erase(it) 后，哪些迭代器会失效？
erase(it) 只会使被删除元素对应的迭代器失效，其他元素的迭代器通常仍然有效，包括删除位置之后的迭代器。

这是 list 相比 vector 的重要优势。
6、deque 在头尾插入删除方面有什么优势？
有专门的函数，时间复杂度是O（1）
7、什么是双向迭代器？list 为什么属于这类迭代器？
就是既可以++，也可以--，list是双向链表所以自然可以双向移动
8、什么是随机访问迭代器？vector 和 deque 为什么支持它？
随机访问迭代器就是可以根据下标随机访问数据，因为这两个底层本质上都是数组
