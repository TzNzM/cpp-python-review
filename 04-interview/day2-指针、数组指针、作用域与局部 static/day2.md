1. 引用和指针调用时有什么区别？
f(x) 和 f(&x) 本身不能直接说是“引用”或“指针”，还要看函数参数声明：
void f(int x);    // f(x)：值传递
void f(int& x);   // f(x)：引用传递
void f(int* x);   // f(&x)：传入地址给指针参数
&x 在这里是“取变量地址”，不是引用语法。
指针可以为空，可以存在空指针。
引用不可以为空。
3. int a[4] 中，a、&a[0]、a + 1 分别表示什么？
a在大多数表达式中会退化成指向第一个元素的指针，等价于 &a[0]；
&a[0]表示这个数组的第一个的值的地址
a + 1：指向第二个元素的指针，不是“数组地址加 1”。
&a
才是“整个数组的地址”，类型是 int (*)[4]，和 int* 不一样。
4. 局部 static 变量和普通局部变量的生命周期有什么区别？
普通局部变量只存在于当前执行这个函数的时候
局部 static 变量在函数第一次调用时就初始化了，然后当这个函数执行完之后，不会把他回收，而是当下一次调用的时候还存在。局部 static 的作用域仍然只在函数内部，但生命周期延长到整个程序结束，并且会保留上一次调用后的值。
