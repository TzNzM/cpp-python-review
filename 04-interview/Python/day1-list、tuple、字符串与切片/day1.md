1. list 和 tuple 的核心区别是什么？
list 可变，适合需要增删改的序列；tuple 不可变，适合固定结构的数据。tuple 通常更轻量，也可以在其元素都可哈希时作为字典 key 或 set 元素。
2. 切片 s[a:b] 包含哪些下标？
左闭右开，包含下标 a，不包含 b。这让 len(s[a:b]) == b - a，并方便连续切片拼接。
3. s[-4:] 常用于什么？
取字符串最后 4 个字符。你的代码中用 name[:-4] 去掉 .jpg，是相对应的前缀切片。
4. append 和 extend 的区别？
append(x) 把 x 当作一个整体放到列表末尾；extend(iterable) 逐个加入可迭代对象的元素。
5. 为什么“不能修改原列表”需要特别留意？
列表是可变对象，函数内原地修改会影响调用方持有的同一个对象，造成隐式副作用。数据处理或训练管线中，这会让后续结果难以复现和排查。你的实现通过创建 cleaned_path，正确避免了该问题。

list的用法：
| 操作     | Python           |
| ------ | ---------------- |
| 创建     | `a = [1, 2, 3]`  |
| 获取长度   | `len(a)`         |
| 访问     | `a[i]`           |
| 修改     | `a[i] = x`       |
| 尾部添加   | `a.append(x)`    |
| 指定位置插入 | `a.insert(i, x)` |
| 添加多个   | `a.extend(b)`    |
| 删除指定下标 | `a.pop(i)`       |
| 删除末尾   | `a.pop()`        |
| 按值删除   | `a.remove(x)`    |
| 查找位置   | `a.index(x)`     |
| 统计次数   | `a.count(x)`     |
| 排序     | `a.sort()`       |
| 新列表排序  | `sorted(a)`      |
| 反转     | `a.reverse()`    |
| 判断存在   | `x in a`         |
| 切片     | `a[l:r]`         |
| 倒序     | `a[::-1]`        |
| 复制     | `a.copy()`       |
| 拼接     | `a + b`          |

| 创建            | `[1, 2, 3]` | `(1, 2, 3)` |
| 是否有序          | ✅           | ✅           |
| 是否可以修改        | ✅           | ❌           |
| `append()`    | ✅           | ❌           |
| `remove()`    | ✅           | ❌           |
| `pop()`       | ✅           | ❌           |
| `sort()`      | ✅           | ❌           |
| `count()`     | ✅           | ✅           |
| `index()`     | ✅           | ✅           |
| 支持切片          | ✅           | ✅           |
| 可以作为 dict key | ❌           | ✅           |
| 可以放入 set      | ❌           | ✅           |
| 常见用途          | 动态数据集合      | 固定的一组数据     |
