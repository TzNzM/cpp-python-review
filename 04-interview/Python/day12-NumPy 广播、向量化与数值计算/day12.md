1. NumPy 广播从哪些维度开始比较？两个维度在什么条件下兼容？
NumPy 从最右侧维度开始比较两个 shape。每一对维度满足以下任意条件即可兼容：
- 两者相等；
- 其中一个为 1；
- 某数组缺少这一维，视为长度 1。
例如：
(4, 3, 2, 2)
(1, 3, 1, 1)
可以广播，因为每一维要么相等，要么其中一方是 1。但 (4, 3, 2, 2) 与 (3,) 相加时，3 会对齐到最后一维 W=2，因此不兼容。
2. axis 与 keepdims=True 分别控制什么？为什么按通道标准化时常要保留维度？
axis 指定在哪些维度上聚合。例如 NCHW 图像 (N, C, H, W) 按通道求均值时：
images.mean(axis=(0, 2, 3))
结果 shape 是 (C,)。
keepdims=True 会保留被聚合维度，长度变为 1：
images.mean(axis=(0, 2, 3), keepdims=True)
结果 shape 是 (1, C, 1, 1)，可以直接与 (N, C, H, W) 广播相减。标准化通常保留维度，就是为了避免手动 reshape，也避免把 C 维错误对齐到最后一维。
3. 向量化相对逐样本 Python 循环有什么性能优势，又可能带来什么内存代价？
向量化把大量逐元素计算交给 NumPy 底层的 C 实现，避免 Python 解释器逐次执行循环，通常速度快很多。
代价是中间数组可能占用较多内存。例如连续写多个数组表达式时，每一步都可能生成临时数组；数据很大时可考虑原地操作、分 batch 处理，或减少不必要的中间结果。
4. * 与 @ 分别表示什么运算？在 shape 不匹配时，应如何分析报错？
* 是逐元素乘法，需要 shape 相同或能广播：
a * b
@ 是矩阵乘法。二维情况下：
(M, K) @ (K, N) -> (M, N)
关键检查是左数组最后一维 K，必须等于右数组倒数第二维 K。若报 shape 错误，先写出两个数组的 shape，再逐维检查：逐元素运算看广播规则；矩阵乘法看这两个内维是否一致。
5. softmax 为什么要先减去每行最大值？为什么交叉熵通常应直接基于 logits 做数值稳定计算，而不是先算概率再取对数？
softmax 为：
exp(x_i) / sum(exp(x_j))
每个 logit 同时减去同一个最大值 m 后：
exp(x_i - m) / sum(exp(x_j - m))
分子分母都乘了同一个 exp(-m)，概率完全不变。但最大的指数变成 exp(0)=1，能防止 exp(1000) 溢出。
若先算概率再取对数，极小概率可能下溢为 0，随后 log(0) 得到 -inf，loss 变成 inf。因此交叉熵通常直接从 logits 用数值稳定的 log-sum-exp 或 log_softmax 计算。PyTorch 中常用的 CrossEntropyLoss 就是这种设计
